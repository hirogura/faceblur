# faceblur

- バージョン: v.0.2.0
- ポート: 3370

自分でホストする「顔ぼかし」サービス. 写真をアップロードすると自動で顔を検出して
ぼかします. 自動検出の位置が違うときは顔ごとに解除したり, 筆ツールで手でぼかしたり
できます.

## できること

| 機能 | 説明 |
| --- | --- |
| ドラッグ＆ドロップ / アップロード | 写真をウィンドウへドロップするか, クリックしてファイルを選びます. 複数まとめて読み込めます. |
| 顔の自動認識 | OpenCV (YuNet) で顔を探し, 検出した顔に自動でぼかします. |
| 顔ごとの解除 | 自動で見つけた顔は 1 つずつ解除できます. 画面の顔をクリックするか, 一覧の「解除」ボタンを押します. |
| 筆ツール | 場所を選んで手動でぼかします. 太さと同じ大きさの円がカーソル位置に表示されます. 消去や 1 歩戻しもできます. |
| 強さスライダー | ぼかしの強さをスライダーで調整します. 画面にはそのまま反映されます. |
| 元画像と比較 | 「元画像と比較する」にチェックを入れると, ぼかしを消した状態を見られます. |
| 保存 | PNG / JPEG で保存します. 保存は元の解像度で行われます. |
| 全てクリア | 「写真」の隣にあるボタンで, サーバーに残ったキャッシュ画像を削除します. |
| アップデート / 再起動 | 画面右上から GitHub からの更新と faceblur サービスの再起動ができます. |

## インストール

```shell
sudo ./scripts/install.sh
```

スクリプトが venv を作り, 依存関係と顔検出モデル (YuNet) を用意して,
systemd のサービスとして登録・起動します.

- 待ち受けは `127.0.0.1:3370` (localhost のみ) です.
- `tailscale serve` がある環境では `https://<端末名>:3370/` でも公開します.
- LAN などに公開したい場合は `FACEBLUR_HOST=0.0.0.0 sudo ./scripts/install.sh`
  のように環境変数を指定してください.

## 使い方

1. 写真をドロップ (またはクリックして選択) します.
2. 自動で顔が検出されてぼかされます.
3. 位置が違えば「選択」モードで顔のフレームをクリックして解除します.
4. 自動検出で拾えなかった場所は「ブラシ」モードで手動でぼかします.
5. 強さスライダーでぼかしの濃さを調整します.
6. 「ぼかした写真を保存」で保存します.
7. サーバーに残った画像は「写真」の横の「全てクリア」で削除できます.

## 設定 (環境変数)

| 変数 | 既定 | 説明 |
| --- | --- | --- |
| `FACEBLUR_HOST` | `127.0.0.1` | 待ち受けるアドレス. `0.0.0.0` で LAN にも公開します. |
| `FACEBLUR_PORT` | `3370` | 待ち受けるポート. |
| `FACEBLUR_ADMIN_TOKEN` | (なし) | 設定すると「再起動」「アップデート」にトークンが必要になります. |
| `FACEBLUR_MAX_UPLOAD` | `41943040` | 1 回のアップロードで受け付ける最大バイト数 (40MB). |
| `FACEBLUR_DETECT_SCORE` | `0.6` | 顔検出の判定しきい値. 小さくすると多くの顔を検出します. |
| `FACEBLUR_DETECT_MAX_SIDE` | `1600` | 顔検出に送る画像の長辺の上限 (px). |
| `FACEBLUR_CACHE_KEEP` | `30` | サーバーに残すキャッシュ画像の枚数の上限. |
| `FACEBLUR_CACHE_MAX_AGE` | `21600` | キャッシュ画像を消すまでの時間 (秒). |
| `FACEBLUR_MODEL_DIR` | `./models` | 顔検出モデル (YuNet) を保存する場所. |

## 内部 API

| メソッド | パス | 説明 |
| --- | --- | --- |
| `GET` | `/` | 画面. |
| `GET` | `/static/*` | CSS / JS. |
| `GET` | `/api/info` | バージョン, リポジトリ URL, モデルの有無. |
| `GET` | `/api/health` | ヘルスチェック. |
| `GET` | `/api/update/status` | アップデートの進行状況. |
| `POST` | `/api/detect` | 画像 (本体) を送ると検出した顔の一覧を返します. 送られた画像はキャッシュに残ります. |
| `POST` | `/api/cache/clear` | サーバーに残ったキャッシュ画像を削除します. |
| `POST` | `/api/restart` | サービスを再起動します. |
| `POST` | `/api/update` | GitHub からアップデートして再起動します. |

## 開発

```shell
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m faceblur --port 3370
.venv/bin/python -m pytest tests -q
```

## 構成

```
faceblur/
  app.py       HTTP サーバーと API
  cache.py     サーバーに残す画像のキャッシュ
  config.py    設定 (環境変数)
  detector.py  顔の検出 (OpenCV / YuNet)
  service.py   アップデート (git pull) と再起動
  static/      画面 (HTML / CSS / JS)
systemd/faceblur.service
scripts/install.sh
models/        顔検出モデル (実行時にダウンロード)
.cache/        受け取った画像のキャッシュ (「全てクリア」で削除)
```
